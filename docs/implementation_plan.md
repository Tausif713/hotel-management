# Implementation Plan - Hotel Management Web App

This document outlines the roadmap for building the premium Hotel Management System.

## 🛠 Technology Stack
- **Frontend**: Vite + React + Tailwind CSS + Framer Motion
- **Backend/Database**: Supabase (PostgreSQL, Auth, Real-time)
- **Icons/UI**: Lucide React + Premium Glassmorphic Design

## 🏗 Database Schema
- `profiles`: Role-based user data
- `tables`: Table metadata & QR status
- `menu_items`: Dishes and pricing
- `orders`: Live order tracking
- `order_items`: Specific dish details
- `payments`: Transaction records

## 🚀 Phases
1. **Foundation**: Project setup, Auth, and Design System.
2. **Menu & Admin**: Dashboard for managing food and staff.
3. **QR Ordering**: Real-time customer interface.
4. **Kitchen/Counter**: Operational panels for staff.
5. **Billing & Analytics**: Reports and GST management.
